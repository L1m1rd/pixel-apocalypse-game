# Pixel Apocalypse — Северные дачи 0.13.0

Один большой район и одна непрерывная жизнь персонажа. Начать выживание → выбрать героя → назвать мир. Исследуйте дачи, ищите припасы, переживайте ночь и непогоду. После гибели — новая попытка.

WASD / стрелки — движение; Shift — бег; C / Ctrl — присесть; E — дверь, обыск или подбор. I / Tab — снаряжение; ЛКМ переносит вещи; ПКМ надевает; Shift + ЛКМ выбрасывает. ЛКМ / Пробел — атака, R — перезарядка, V — смена оружия, Q — быстрый предмет, F — фонарь, M — карта, J — журнал и изготовление. Колесо — масштаб; H — скрыть интерфейс; Esc — пауза.

Восемь кварталов, 80 домов, мебель, разные автомобили, тёплый свет и растительность. В 0.13 используются 136 видов домов, машин и мебели в восьми направлениях, включая прямые фасады и профили. Добавлены горизонтальные и вертикальные на экране дороги. Растения приглушены и растут группами по всему району. Лут случаен для каждого мира и сохраняется после обыска. Шаг героя и мобов привязан к пройденному расстоянию; при обходе препятствий они смотрят по фактическому движению. Во всех 18 моделях заражённых исправлены размеры кадров, опорные точки и проигрывание действий. Вещи в инвентаре, обыске, на земле и в уведомлении подбора показываются картинками. Название видно в подсказке и описании выбранной вещи.

Сохранения: %APPDATA%/PixelApocalypse-ContinuousSurvival. Старые сохранения деревни обновляются с сохранением найденных вещей и положения внутри дома.

Подготовка: npm install; npm --prefix desktop install; npm run prepare:desktop. Запуск: npm start. Сборка: npm run package:desktop.

Проверки: node --test desktop/*.test.mjs; node tools/check-asset-consistency.cjs; node tools/check-village-assets.cjs; node tools/check-village-directions.cjs; node tools/check-v013-runtime.cjs.
