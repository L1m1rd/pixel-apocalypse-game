# Тестовая десктопная версия 0.2

Минимальная локальная Windows-версия: анимированное главное меню C с живыми кнопками, выбор одного из шести героев, поворот героя при выборе, создание мира с названием, поле 8192×8192 с единственной канонической текстурой grass_short_a. Герой стоит, ходит, бежит, приседает, крадётся и встаёт; у каждого действия четыре направления. Камера следует за героем.

## Запуск готовой сборки

[Скачать Windows x64 из релиза 0.2](https://github.com/L1m1rd/pixel-apocalypse-game/releases/tag/prototype-v0.2.0). Полностью распакуйте ZIP и откройте PixelApocalypse.exe в извлечённой папке.

Дважды щёлкнуть `Запустить игру.cmd` в корне проекта или `output/PixelApocalypse-test-v0.2.0-win32-x64/PixelApocalypse.exe`. Все соседние файлы сборки должны оставаться рядом с EXE. Node.js, терминал и браузер для готовой сборки не нужны.

В 0.2 исправлена привязка всех кадров к общей оси персонажа: ожидание и движение больше не содержат прежнего бокового смещения. Новый боковой бег — восемь кадров на направление. Облака за окном движутся отдельным слоем со скоростью 5 пикселей/с; маска сохраняет перед ними башню, деревья и раму. Папка предыдущей сборки сохранена, новый запуск направлен на 0.2.

«Создать мир» → выбрать героя → «Далее» → название → «Создать мир». Один локальный слот сохраняется автоматически. «Продолжить» возвращает того же героя на прежнее место; новый мир заменяет предыдущий слот. Сохранение хранится в пользовательской папке приложения Electron, файл `world-v1.json`.

| Клавиши | Действие |
|---|---|
| WASD / стрелки | Движение |
| Shift + движение | Бег |
| C / Ctrl | Присесть / встать |
| Движение сидя | Красться |
| Esc | Пауза / продолжить |
| F11 | Полный экран |

Враги, предметы, здания, инвентарь, крафт, бой и сеть не добавлены. «Подключиться» и «Настройки» в меню пока недоступны. Сохранения и пауза служат проверке этого минимального прототипа.

## Исходники и сборка

`npm --prefix desktop install` устанавливает Electron. `npm start` из корня запускает исходники при подготовленной папке media.

`npm run prepare:desktop` экспортирует в desktop/media производные атласы из утверждённых анимаций, копирует траву и вырезает сцену меню из готовой анимации. Канонические ассеты не перерисовываются и новые игровые предметы не создаются. Для экспорта нужны sharp и зависимости корневого package.json. Состав и источники сохранены в desktop/media/asset-manifest.json; сама производная папка исключена из Git и восстанавливается экспортом.

`npm run build:desktop` собирает переносимую папку output/PixelApocalypse-test-v0.2.0-win32-x64. Это отдельное окно Electron с Canvas 2D; локальный сервер и браузерный запуск не используются. Рендерер изолирован от Node.js, сохранения проходят через ограниченный IPC с проверкой данных.

Источники бокового бега: desktop/art/locomotion-v2; запросы image_gen и происхождение сохранены там же. Источник неба и маска извлечённого переднего плана — desktop/art/menu-clouds. tools/export-locomotion-fixes.cjs нарезает новые фазы; tools/normalize-locomotion.cjs выравнивает производные кадры при экспорте. tools/prepare-menu-clouds.cjs подготавливает бесшовный слой и маску. Канонический старый набор анимаций сохраняется; приложение использует исправленные производные.

## Проверка

- `node --test desktop/core.test.mjs` — скорость диагоналей, границы, приседание, бег и валидация сохранений.
- `node tools/test-desktop.cjs` — проверка исходного приложения в реальном окне Electron.
- `node tools/test-desktop.cjs --packaged` — такая же проверка готового EXE.

Для интеграционных проверок нужен Playwright из зависимостей корневого проекта. Они используют отдельную временную папку сохранений и не изменяют пользовательский мир. Отчёты и скриншоты — output/desktop-test.
