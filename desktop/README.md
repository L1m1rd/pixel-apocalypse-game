# Северные дачи — версия 0.3

Проходимая карта большого района из карты «Кольцо вокруг города»: 80 участков, 60 дач, восемь секторов, огороды, теплицы, сараи, колодец, лесополоса, река с мостом и выход на кольцевую. Используются 34 подготовленных изображения окружения. Камера с высоким фиксированным ракурсом, объекты сортируются по глубине; кроны возле героя становятся прозрачнее.

Запуск готовой сборки — через «Северные дачи.cmd» или PixelApocalypse.exe в соседней папке сборки. Node.js для готовой сборки не нужен.

WASD / стрелки — движение в направлениях экрана; Shift — бег; C / Ctrl — присесть; E — ближайшие ворота; M — карта; колесо — масштаб; H — скрыть интерфейс; Esc — пауза; F11 — полный экран.

Позиция героя и открытые ворота сохраняются в отдельном профиле PixelApocalypse-NorthernDachas. Исходный мир другой сборки не заменяется. Все дома пока представлены цельными непроходимыми постройками; интерьеры, бой и заражённые не подключены.

Карта и столкновения — northern-dachas-map.mjs; изображение и обзор — northern-dachas-renderer.mjs; экспорт канонических ресурсов — tools/prepare-northern-dachas-runtime.cjs. Земля рисуется по видимым блокам с ограниченным кэшем.

Из исходников: установить зависимости корня и desktop, затем npm run prepare:desktop и npm start. Сборка: npm run build:desktop.

Проверки: node --test desktop/core.test.mjs desktop/northern-dachas-map.test.mjs; node tools/check-asset-consistency.cjs; node tools/check-northern-dachas.cjs; node tools/check-northern-dachas-runtime.cjs. Готовая сборка: последняя команда с --packaged. Проверки запуска используют отдельный тестовый профиль.

Рабочая ветка этого чата — codex/northern-dachas. После каждого запроса готовые проверенные изменения отправляются туда. Подробнее: docs/northern-dachas-release.md.
