# Pixel Apocalypse — Северные дачи 0.15.0

[Играть в браузере](https://l1m1rd.github.io/pixel-apocalypse-game/) · сохранение хранится локально в браузере.

Один район, одна непрерывная жизнь персонажа. Начать выживание → выбрать героя → назвать мир. Исследуйте дачи, ищите припасы, переживайте ночь и непогоду. После гибели — новая попытка.

Восемь кварталов, 80 домов, шесть проходимых планировок с одинаковой стороной входа, отдельные комнаты, шкафы с припасами, кровати и печи. Дороги меняют ширину. В лесу рощицы, поляны, съедобные ягоды и камни для будущей добычи. При входе камера плавно приближается; за домом герой выделяется белым контуром.

WASD / стрелки — движение; Shift — бег; C / Ctrl — присесть; E — дверь, багажник, обыск или подбор. I / Tab — снаряжение; ЛКМ переносит вещи; ПКМ надевает; Shift + ЛКМ выбрасывает. У одежды собственные карманы. Полный рюкзак и одежда сохраняют содержимое при снятии. ЛКМ / Пробел — атака, R — перезарядка, V — смена оружия, Q — быстрый предмет, F — фонарь, M — карта, J — журнал и изготовление. Колесо — масштаб; H — скрыть интерфейс; Esc — пауза.

Сохранения: %APPDATA%/PixelApocalypse-ContinuousSurvival. Старые миры обновляются с сохранением инвентаря, обыска и вещей в помещениях. Новые персонажи получают четыре ячейки при себе и дополнительные карманы одежды; лишние ячейки старого сохранения освобождаются постепенно, без удаления вещей.

Подготовка: npm install; npm --prefix desktop install; npm run prepare:desktop. Запуск: npm start. Сборка: npm run package:desktop.

Проверки: node --test desktop/*.test.mjs; node tools/check-asset-consistency.cjs; node tools/check-village-assets.cjs; node tools/check-village-directions.cjs; node tools/check-v015-runtime.cjs.

[Подробности 0.15](../docs/village-v015.md) · [Предыдущие ракурсы и анимации 0.13](../docs/village-v013.md).

В 0.15 убрана отдельно нарисованная дверь и её анимация: вход открывается мгновенно. Листва фасадов приглушена отдельно от стен и крыши. Заражённые неподвижны в покое; при ходьбе и беге чередуют обе ноги. Поле зрения героя перекрывают стены, перегородки, деревья, машины и крупные препятствия. Скрытые заражённые и предметы не отображаются на мини-карте. Заражённые смотрят в своём секторе, слышат шаги и выстрелы и ищут последнюю известную позицию. Присед уменьшает заметность и шум, заросли дают дополнительное укрытие. Белый/жёлтый/красный глаз над героем показывает скрытность, подозрение и обнаружение. Обыск и лечение сопровождаются круговым прогрессом; E или движение отменяет действие.
