# Pixel Apocalypse — Северные дачи 0.11.0

Один большой район и одна непрерывная жизнь персонажа. Начать выживание → выбрать героя → назвать мир. Исследуйте дачи, ищите еду, воду и снаряжение, переживайте ночь и непогоду. После гибели — новая попытка.

WASD / стрелки — движение; Shift — бег; C / Ctrl — присесть; E — дверь, обыск или подбор. Войдите через открытую дверь, чтобы увидеть интерьер. I / Tab — снаряжение; ЛКМ переносит вещи; ПКМ надевает; Shift + ЛКМ выбрасывает. ЛКМ / Пробел — атака, R — перезарядка, V — смена оружия, Q — быстрый предмет, F — фонарь, M — карта, J — журнал и изготовление. Колесо — масштаб; H — скрыть интерфейс; Esc — пауза.

Карта: восемь кварталов, 80 домов с мебелью, разными фасадами и автотранспортом. Тёплый дневной свет, контактные тени и плотная растительность. Белая обводка показывает доступные объекты. Двери, стены, мебель и ограды имеют столкновения.

Мир и вещи сохраняются автоматически, в том числе при нахождении в доме. Сохранения находятся в %APPDATA%/PixelApocalypse-ContinuousSurvival. Профиль кампании 0.10.0 оставлен отдельно.

Подготовка: npm install; npm --prefix desktop install; npm run prepare:desktop; node tools/prepare-village-assets.cjs. Запуск: npm start. Сборка: npm run package:desktop.

Проверка: node --test desktop/*.test.mjs; node tools/check-village-assets.cjs; node tools/check-village-runtime.cjs; node tools/check-village-interiors.cjs.

Объём, устройство и ограничения: [Описание выпуска](../docs/continuous-survival-v011.md). Это собственная реализация непрерывного выживания по запросу пользователя, а не заявление о полном совпадении с Mini DAYZ 1.
