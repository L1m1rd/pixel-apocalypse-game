# Полигон предметов — версия 0.6.0

Активная карта полностью пуста: ровное покрытие 8192 × 8192 и герой. Построек, растительности, дорог, противников и начального лута нет. Карта Северных дач 0.5.0 сохранена в исходниках и в предыдущей сборке.

I или Tab открывают инвентарь. Во вкладке «Все предметы» доступны 268 вариантов 245 канонических переносимых сущностей: 24 модели огнестрельного оружия, нож, топор, одежда и снаряжение, инструменты, еда и вода, медикаменты, патроны, ресурсы и методички. Персонажи, эффекты, декорации и непереносимые объекты окружения в инвентарь не попадают.

Из каталога можно взять один предмет или полный стак. Рюкзак: экипировка и снятие, объединение и разделение стаков, выбрасывание и подбор. Базовая вместимость 24 ячейки; рюкзаки расширяют её до 28–60. Нельзя снять или заменить рюкзак, если вещи перестанут помещаться. Вес показывается справочно, ограничения веса пока нет.

Еда, вода и медикаменты изменяют соответствующие показатели героя. Сырое мясо снижает здоровье. Методички сохраняют изученные знания. Материалы, семена и технические предметы имеют операции хранения; крафт, строительство и выращивание на этом этапе не реализованы. Надетая одежда отображается в слотах; спрайт персонажа пока не меняется.

R заряжает экипированное оружие подходящим семейством патронов. Пробел выполняет тестовый выстрел с расходом одного патрона. Пока без боевой анимации, звука и урона. Тестовый боезапас разделён на три семейства; единица стака равна одному патрону. Открытая и закрытая коробки — состояния одного канонического предмета.

WASD / стрелки — движение, Shift — бег, C / Ctrl — присесть, E — подобрать ближайший предмет, M — карта, колесо — масштаб, H — интерфейс, Esc — закрыть окно / пауза, F11 — полный экран. Инвентарь и карта останавливают движение; стрелять при открытых окнах нельзя.

Профиль сохранений PixelApocalypse-ItemLab отделён от профиля Северных дач. Сохраняются герой, позиции, рюкзак, экипировка, заряженные патроны, предметы на земле, показатели и прочитанные методички.

Подготовка: npm run prepare:desktop. Запуск: npm start. Сборка: npm run build:desktop.

Проверки: node --test desktop/core.test.mjs desktop/inventory.test.mjs; node tools/check-item-lab-assets.cjs; node tools/check-item-lab-runtime.cjs. Проверка сборки: последняя команда с --packaged и PIXEL_APOCALYPSE_OUTPUT.
