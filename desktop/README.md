# Полигон предметов — версия 0.6.1

Пустая карта 8192 × 8192 для проверки передвижения и переносимых предметов. Северные дачи сохранены в исходниках и предыдущей сборке 0.5.0.

## Движение

WASD и стрелки задают направления экрана: W вверх, S вниз, A влево, D вправо. Экранное смещение преобразуется в координаты изометрической карты. Скорость диагонали равна скорости прямого движения. Shift — бег; C / Ctrl — присесть. Инвентарь, творческий каталог, карта и пауза останавливают движение.

## Снаряжение и хранение

I или Tab открывают обычный инвентарь: слева снаряжение вокруг персонажа по утверждённому макету, в центре отдельные сетки карманов и рюкзака, справа осмотр выбранной вещи и действия. Основные слоты: шлем, броня, штаны, оружие, рюкзак, противогаз, перчатки и ботинки. Дополнительные: футболка, куртка, поножи и инструмент. Надетая одежда пока не меняет спрайт героя.

Карманы имеют 12 ячеек и доступны без рюкзака. Хранилище рюкзака появляется только после надевания рюкзака; вместимость зависит от его уровня (28–60 ячеек). Вещи можно переносить между сетками кнопками и перетаскиванием, а на слоты снаряжения — перетаскиванием или кнопкой «Надеть». Неподходящие слоты и переполненные отделения отклоняют перенос целиком.

У каждого рюкзака своё содержимое. Снятие, замена, выбрасывание, подбор и сохранение рюкзака сохраняют все вещи внутри него. Наполненный рюкзак можно нести в карманах как отдельный предмет; вкладывать один рюкзак в другой нельзя. Операции разделения и объединения стаков не переносят вещи между отделениями автоматически.

Еда, вода и медикаменты применяются из карманов и рюкзака. Методички сохраняют знания. Материалы, семена и технические предметы поддерживают хранение и перенос; применение в мире пока отдельно. Показанный вес справочный, ограничение веса ещё не введено.

## Творческий режим

Обычный инвентарь содержит только вещи персонажа. Выдача 268 вариантов 245 канонических переносимых сущностей вынесена в отдельное окно. По умолчанию режим выключен. Для проверки включить флажок «Творческий режим» в инвентаре, затем нажать «Каталог · F2» или F2. Выдача явно направляется в карманы либо в надетый рюкзак. При выключении режима выдача блокируется; уже полученные вещи остаются у персонажа.

R — зарядить экипированное оружие патронами из карманов или рюкзака. Пробел — тестовый выстрел с расходом одного патрона, пока без боевой анимации и урона. E — подобрать ближайшую вещь в карманы. M — карта; колесо — масштаб; H — скрыть интерфейс; Esc — закрыть верхнее окно / пауза; F11 — полный экран.

## Сохранение и проверки

Профиль PixelApocalypse-ItemLab. Сохраняются оба отделения, все слоты, содержимое снятых рюкзаков, предметы на земле, патроны, показатели героя, знания и состояние творческого режима. Сохранения 0.6.0 автоматически преобразуются: вещи старой общей сумки перемещаются в надетый рюкзак, либо в карманы; излишки карманов остаются рядом на земле с уведомлением. Сохранения Северных дач не затрагиваются.

Подготовка: npm run prepare:desktop. Запуск: npm start. Сборка: npm run build:desktop.
