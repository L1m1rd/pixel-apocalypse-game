# Дома с ровным входом без крыльца

Шесть фронтальных фасадов `house-0-0_5` … `house-5-0_5` отредактированы встроенным `image_gen`: удалены лестницы, ступени, настилы, перила, навесы крыльца и предметы перед входом. Дверной проём выходит прямо к земле. Отдельный спрайт двери и взаимодействие E сохранены.

Все варианты относятся к существующему `world/house` (владелец `environment-variants-v1/house`); дверь по-прежнему использует владельца `world/door`. Новых игровых предметов нет. Первые варианты с крыльцом сохранены в соседней папке `house-doorless-v1` как история.

Запросы и источники: `generation-records.json`. Проверенные координаты проёмов: `door-openings.json`. Runtime подготавливается командой `node tools/prepare-village-directions.cjs`. Браузерная проверка всех шести типов: `node tools/check-house-doors-web.cjs`.
