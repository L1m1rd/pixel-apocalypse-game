# Ракурсы деревни · 0.12.0

68 игровых PNG с прозрачностью: шесть стилей дома × четыре стороны, шесть автомобилей × четыре стороны, стол, кровать, шкаф, полки и печь × четыре стороны. Камера остаётся изометрической, направления меняют сами предметы. Дневной свет падает сверху слева.

Это варианты семи существующих канонических сущностей: world/house, world/car_abandoned, world/table, world/bed, world/wardrobe, world/shelves и item/base-stove. Их владельцы указаны в manifest.json. Новых игровых предметов нет; прежние стили домов и машин не дублируются в инвентаре.

Изображения созданы встроенным image_gen. Полные запросы — [prompts.json](prompts.json), выбранные исходники — sources/, готовые изображения — sprites/. Шесть отдельных атласов домов дают более 400 пикселей по ширине на каждую сторону. Прототип общего маленького атласа домов в этот набор не входит.

Порядок сторон: south, east, north, west. Это фиксированные четверть-обороты в мире, а не вращение камеры. В игре с домом поворачиваются дверной проём, стены, мебель и её столкновения. Для автомобиля поворачивается прямоугольник столкновения. Мелкая растительность и уличный декор используют вариации отражения.

Подготовка: node tools/prepare-village-directions.cjs. Повторная нарезка из выбранных исходников: добавить --export. Проверка: node tools/check-village-directions.cjs и node tools/check-asset-consistency.cjs.
