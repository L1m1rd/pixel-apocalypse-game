# Новые заражённые — утверждённый набор анимаций

**Пользователь одобрил все новые анимации и поручил загрузить их в приватный GitHub.** Это актуальный набор для 18 новых образов. Таблица статичных моделей и отдельные изображения сохранены рядом в проекте. Старые наборы анимаций оставлены как предыдущие итерации.

## Состав

- 18 новых образов: шесть видов × классы A/B/C.
- A — слабый, B — средний, C — сильный внутри своего вида. Численные параметры пока не заданы.
- Четыре направления: south / вниз и спереди, west / влево, east / вправо, north / вверх и со спины.
- Восемь общих действий у всех: ожидание, ходьба, бег/рывок, атака, получение урона, оглушение, отбрасывание, смерть.
- Три бронированных дополнительно имеют бросок нароста.
- Три босса дополнительно имеют подготовку/бег/столкновение тарана, двойной удар, удар по земле, рёв второй фазы и переход в ярость.
- Всего **672 анимации, 4032 прозрачных PNG-кадра, 72 неподвижных тела**. По шесть кадров в анимации.

## Просмотр

Откройте `preview.html` двойным щелчком после распаковки. Это локальный просмотрщик графики, не браузерная игра. Доступны вид, класс, действие, направление, пауза, покадровый просмотр, скорость и светлый фон. Для каждого вида можно сравнить A/B/C сразу в четырёх ракурсах.

Смерть останавливается на последнем кадре. Короткие приёмы в просмотрщике и GIF повторяются с паузой для оценки; в игровых настройках они однократные. Ожидание, ходьба, бег, оглушение и бег тарана зациклены. Физическое перемещение не запечено в кадры: `rootMotion: false`.

В папках `01-A`…`06-C` лежат четыре направления, в каждом — отдельные PNG, спрайт-лист, JSON-атлас, настройки и GIF отдельных анимаций. `corpse.png` совпадает с последним кадром смерти и остаётся неподвижным. `comparisons` содержит четырёхракурсные GIF каждого действия, а также составные ролики тарана и переходов фаз для трёх боссов. `families` показывает три класса одного вида одновременно.

## Эффекты сохранены

Частицы, кровь, споры, летящий нарост и пыль удара не перерисовывались. Прежние папки `assets/combat-vfx-v1`, `assets/infected-animation-pack-v5/fx`, `assets/infected-specials-v1/fx` сохранены побайтно. Их 284 файла зафиксированы контрольными суммами в `unchanged-effects-before.json`; итоговая проверка сравнивает их с текущими файлами. Новые кадры персонажей не содержат добавленных облаков или крови поверх тела.

## Исходники и экспорт

Графика создана встроенным image_gen по утверждённым пиксельным референсам. `generation-prompts.json` содержит все запросы, `references` — 18 образов, `sources` — исходные листы. Дополнительные исправления записываются отдельно. `source-crops.json` в каждом направлении сохраняет координаты нарезки; масштаб каждого персонажа одинаков для всех его действий и ракурсов.

`manifest.json` перечисляет весь состав, классы, действия, длительности и пути. `verification.json` содержит результаты проверок кадров, атласов, тел, неизменности эффектов и просмотрщика. Это ресурсы и метаданные для будущего подключения; ИИ, бой, физика и сетевой код не добавлены. Координаты выпуска снарядов на руках предстоит привязать при визуальной интеграции; старые координаты к новым телам не перенесены автоматически.

Архивы для просмотра находятся в `output/redesigned-animation-review` исходного проекта: один общий и по одному на каждый вид. Для компактности архивы включают готовые кадры, GIF, референсы, настройки и просмотрщик, а исходные генерации остаются в папке `sources` проекта. Прежние эффекты также остаются в своих существующих наборах.
