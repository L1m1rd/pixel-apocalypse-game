# Выжившие — статичный визуал v1

Шесть персонажей: Джоэл, Элли, Томми, Тесс, Билл, Дина. Внешность вдохновлена сериалом HBO The Last of Us; одежда адаптирована под выбранную пиксельную палитру проекта.

Каждый PNG содержит три статичных ракурса одного персонажа. Слева направо: **левый бок (west), правый бок (east), со спины (north)**. Вид спереди исключён по запросу пользователя. Элли показана взрослой, по образу второго сезона.

`overview.png` — общий лист для сравнения. Отдельные файлы `joel.png`, `ellie.png`, `tommy.png`, `tess.png`, `bill.png`, `dina.png` — PNG с прозрачным фоном.

Это изображения для выбора внешнего вида, не анимации и не готовые игровые атласы. Направления и внешний вид следует утвердить до создания движений и точной игровой нарезки.

Создано встроенным image_gen. Полные запросы сохранены в `generation-prompts.json`. `validation.json` проверяет размеры, прозрачность и наличие содержимого в трёх колонках; визуальное соответствие ракурсам проверяется отдельно.
