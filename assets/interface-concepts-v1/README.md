# Варианты интерфейса

18 визуальных предложений: шесть экранов × три варианта. Для всех экранов выбран A; актуальные утверждённые макеты находятся в ../interface-selected-v1. Интерфейс в игру не внедрён.

A — полевой; B — бумажный; C — контрастный. Выбирать можно отдельно для каждого экрана. Кнопки, показатели и рецепты показаны как предложения и не фиксируют игровые правила.

Исходные макеты созданы встроенным image_gen. generation-prompts.json содержит точные запросы. Листы comparison — только компоновка и масштабирование исходников.
