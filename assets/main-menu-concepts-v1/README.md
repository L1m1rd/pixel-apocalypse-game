# Главное меню — три варианта

Три визуальных предложения в утверждённом полевом стиле интерфейса A: тёмные полупрозрачные панели, оливковый акцент, светлые подписи и пиксельная графика.

- **A — Заброшенная деревня:** меню слева, пасмурное утро.
- **B — Лесная дорога:** меню по центру, сумерки.
- **C — Убежище:** меню справа, тёплый свет фонаря в помещении.

Общие пункты: «Продолжить», «Создать мир», «Подключиться», «Настройки», «Выход». В примере «Продолжить» недоступно до появления сохранения; это предложение для визуального состояния кнопки, а не реализация сохранений.

PIXEL APOCALYPSE — рабочая надпись для макета, окончательное название не утверждено. Все три изображения ожидают выбора пользователя. Код игрового меню не создавался.

Макеты созданы встроенным image_gen. Точные запросы: generation-prompts.json. Ссылка на стиль: ../interface-selected-v1/01-hud.png.
