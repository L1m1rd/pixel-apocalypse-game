|---|---|

Распакуйте архив и откройте `preview.html`, чтобы переключать действия, героев и направления. PNG/GIF доступны без просмотрщика. Оружие и предметы добавляются отдельными слоями, рюкзаки не встроены.

Оригинальные листы генерации доступны в [sources](../sources), экспортированные PNG анимаций — в папках героев. Архивы содержат готовые кадры и превью, исходники генерации не дублируют.
