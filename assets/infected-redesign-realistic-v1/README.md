# Реалистичные прототипы заражённых — выбор внешности

18 отдельных реалистичных концептов, шесть ролей по три разных варианта. Это вымышленные персонажи, не фотографии реальных людей. Арты созданы встроенным image_gen, без использования прежних изображений заражённых как входных референсов. Первоначальные запросы: [generation-prompts.json](generation-prompts.json); смягчённые варианты для части изображений: [revision-prompts.json](revision-prompts.json). В этой итерации пиксельные персонажи и анимации не создаются.

Задача — сохранить мрачную атмосферу человеческой инфекции и игровые роли, исследовать самостоятельные формы мутаций и силуэты. Пользователь утвердил **все 18 образов**: каждый из шести видов получает три класса. **A — слабый, B — средний, C — сильный внутри своего вида.** Численные параметры силы пока не заданы; сейчас выполняется только визуальная часть.

В [art](art) лежат все 18 самостоятельных PNG в исходном разрешении. [Общий лист](overview.png) и шесть сравнений добавляют подписи к уменьшенным копиям, не заменяя оригиналы. [Описание концептов](prototypes.json) содержит отличия каждого варианта. [Отчёт](verification.json) содержит размеры, пути и SHA-256.

Коды `01-A`…`06-C` сохраняются для связи реалистичного референса с пиксельным образом. Все A/B/C включаются в состав проекта; выбирать один вариант больше не требуется. Старые листы и анимации сохранены отдельно как предыдущая итерация.
