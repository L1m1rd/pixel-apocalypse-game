# Заражённые — четыре направления, v2

**6 типов × 4 направления × 4 действия × 6 кадров = 96 анимаций, 576 PNG-кадров.**

Направления: `south` — спереди/вниз, `west` — влево, `east` — вправо, `north` — со спины/вверх.

Действия: `idle` — ожидание, `walk` — ходьба, `run` — бег/тяжёлый рывок, `attack` — атака. Нумерация кадров `00`–`05`.

## Просмотр

Распакуйте ZIP целиком. Откройте `preview.html`: выбор заражённого, четыре направления рядом, четыре действия, пауза, покадровый шаг, скорость и светлый фон. Файл работает локально без сервера. Это просмотрщик графики, а не браузерная версия игры.

В `comparisons` — 24 GIF, на каждом одно действие одного заражённого сразу в четырёх направлениях. Порядок слева направо: спереди, влево, вправо, со спины. В `<тип>/<направление>/previews` — 96 отдельных GIF.

## Игровые файлы

В `<тип>/<направление>/` лежат:

- `spritesheet.png`: прозрачный RGBA, 6 столбцов × 4 строки, без отступов. Строки: idle, walk, run, attack.
- `atlas.json`: Phaser JSON Hash, именованные кадры.
- `animations.json`: кадры, длительности, частоты, повторы, origin и визуальный момент атаки.
- `frames/*.png`: отдельные кадры.
- `source-crops.json`: координаты исходных поз, масштаб и контрольные суммы.
- `validation.json`: проверки экспорта.

Размер кадра: бегун/сталкер/щелкун — 64×64; топляк/шаркун — 96×96; Крысиный король — 128×128. В пределах типа размер и точка привязки одинаковы во всех направлениях. Поля кадра оставлены для размаха атаки. Масштаб силуэтов нормализован по высоте ожидания; у сторон сложного босса возможны небольшие художественные отличия.

## Phaser

В `phaser-infected.js` — загрузка 24 листов, регистрация 96 анимаций, создание спрайта и выбор направления по вектору движения. В `preload` вызовите `preloadInfected(this)`, в `create` — `createInfectedAnimations(this)`. Пример: `playInfected(enemy, 'runner', 'run', 'north')`.

Для спрайтов включите `pixelArt: true`, сохраняйте origin из метаданных. Боковые направления имеют отдельные изображения: зеркалить `west` или `east` в движке не нужно. Диагональные направления в набор не входят.

Ожидание, ходьба и бег зациклены. Атака в игровых JSON однократная. Четвёртый кадр (`event.frame: 3`) — визуальный контакт/выброс спор; он не заменяет серверную проверку попадания. GIF и просмотрщик повторяют атаки для сравнения. Облако спор — отдельный будущий эффект.

Графика не реализует перемещение, физику, ИИ, урон и онлайн. Полноценная проверка интеграции с игрой предстоит отдельно.

## Происхождение и статус

Позы созданы встроенным image_gen на основе согласованного дизайна v1. Новые боковые и задние ракурсы нарисованы отдельно; передний вид перенесён из v1. Все исходные листы сохранены в `sources`, запросы — в `generation-prompts.json`. Для нарезки выделяются отдельные силуэты, поэтому рука, выходящая за условную ячейку исходника, целиком остаётся в своём кадре. Движения не создаются перемещением одной статичной картинки.

Это набор для прототипа и пользовательского просмотра. Возможны небольшие колебания деталей между сгенерированными позами; при необходимости их можно отполировать после просмотра. Технические проверки и просмотрщик не заменяют художественное одобрение.

Сборка: `tools/build-infected-v2.cjs` и `tools/slice-sprite-components.cjs`, Node.js с sharp и jszip. Итоговые файлы полностью автономны. Публикация на GitHub ожидает одобрения пользователя.
