# Главное меню C — лёгкая зацикленная анимация

Выбранное пользователем меню C. Пламя фонаря и печи, лёгкое покачивание плюща у окна и мягкое мерцание света. Камера, кнопки, надписи, мебель и правая панель неподвижны.

48 кадров × 100 мс = 4,8 секунды, бесконечный цикл. preview.gif — уменьшенное превью; main-menu.webp — анимация полного разрешения 1672×941; frames — все PNG. Отдельные слои и исходники находятся в layers и sources; параметры — manifest.json.

Художественные слои созданы встроенным image_gen. Сборка движения и экспорт — tools/build-main-menu-animation.cjs. Запросы и происхождение — generation-records.json. Игровые кнопки и их обработчики ещё не реализованы. В GIF/WebP кнопки являются частью изображения; при интеграции их следует сделать интерактивными элементами поверх фона. Название игры рабочее.

Публикация одобрена пользователем. [Полный ZIP](https://github.com/L1m1rd/pixel-apocalypse-game/releases/tag/main-menu-animation-v1) прикреплён к отдельному релизу; отдельные файлы хранятся в репозитории.
