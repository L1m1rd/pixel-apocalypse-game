## Формат и готовность

- Графика создана встроенным **image_gen**. Все 16 исходных листов находятся в sources, запросы сохранены в generation-prompts.json.
- Art содержит 96 прозрачных PNG 256×256 для просмотра; sprites — 96 прозрачных изображений 64×64, 96×96 или 128×128.
- Размеры выбраны для визуального прототипа. Масштаб относительно персонажа, размеры на карте, точки крепления и коллизии ещё предстоит настроить. Размеры и формы не являются готовой системой тайлов.
- Подписи находятся только на сравнительных листах. Отдельные игровые изображения не содержат подписей и фона.
- Для предметов показан один статичный вид. Открытие, включение, использование, переноска и остальные состояния ещё не анимированы.
- Поля kind группируют визуалы по назначению для просмотра; они не реализуют инвентарь или взаимодействия.
- Это первая визуальная итерация. Наличие аптечки, машины, генератора или грибного объекта не означает реализацию соответствующей механики.
- Новые иконки оружия в этой коллекции иллюстрируют предметы лута. [Отдельный набор из 24 моделей и 48 анимаций](../weapon-animations-v1/README.md) сохраняется самостоятельно.

Экспорт: `node tools/build-item-visuals.cjs`. Проверка: `node tools/check-item-visuals.cjs`. Упаковка: `node tools/package-item-visuals.cjs`. Скрипты нарезают и упаковывают готовую графику, не рисуют новые предметы.
