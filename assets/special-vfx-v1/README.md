# Специальные эффекты

Четыре эффекта, по шесть кадров: **growth_projectile**, **spore_burst**, **spore_cloud**, **slam_dust**. Всего 24 кадра.

Изображения перенесены без изменений в самостоятельную папку, чтобы эффекты не зависели от устаревших моделей заражённых.

[Манифест](manifest.json) задаёт кадры, размеры, время и точки привязки. В папке каждого эффекта находятся PNG, спрайт-лист, настройки и GIF. Урон, полёт снаряда и зоны спор реализуются игровой логикой.
