# Выбранный интерфейс — A

Все шесть экранов используют выбранное пользователем направление A. HUD обновлён: блок задач справа удалён. В снаряжение инвентаря добавлены отдельные слоты штанов и противогаза, всего восемь слотов. Остальные четыре экрана скопированы без перерисовки из выбранных вариантов A.

Это визуальные макеты. Внедрение в игру не выполнено. Портреты, фоны, предметы, рецепты и значения внутри макетов примерные. Все шесть макетов и правки одобрены пользователем для публикации.

Изменения выполнены встроенным image_gen; точные запросы и происхождение находятся в generation-records.json. Решения сохранены в ../interface-concepts-v1/selection.json и ../../docs/interface-direction.md.
