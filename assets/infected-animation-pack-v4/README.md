# Заражённые — объединённый набор v4

Актуальные графические ресурсы для шести типов в четырёх направлениях: south, west, east, north. **192 анимации, 1152 прозрачных кадра и 24 отдельных статичных тела.**

| Строка атласа (с нуля) | Действие | Повтор |
|---|---|---|
| 0 | idle | Цикл |
| 1 | walk | Цикл |
| 2 | run | Цикл |
| 3 | attack | Один раз |
| 4 | hurt | Один раз |
| 5 | stunned | До снятия оглушения |
| 6 | knockback | Один раз |
| 7 | death | Один раз, удерживать тело |

По шесть кадров в каждой строке. 24 спрайт-листа (шесть колонок × восемь строк), Phaser JSON Hash атласы, отдельные PNG, настройки, 192 GIF движений и 48 GIF сравнений направлений. Тела `corpse.png` совпадают с последним кадром `death` и не добавляют фиктивных анимаций.

Откройте [preview.html](preview.html) двойным щелчком. По умолчанию показаны смерть и статичные тела. Фильтр открывает все действия. Смерть останавливается на последнем кадре; «Повторить» перезапускает просмотр. GIF повторяются для демонстрации с задержкой на теле. На GitHub HTML показывается исходным кодом, поэтому просмотрщик открывают локально.

## Использование в Phaser

В [phaser-infected.js](phaser-infected.js) находятся загрузка атласов, регистрация анимаций и примеры:

```js
// preload:
preloadInfected(this, 'assets/infected-animation-pack-v4');
// create:
createInfectedAnimations(this);
const enemy = addInfectedSprite(this, 'runner', 300, 200, 'west');
// On transition to dead:
playInfectedDeath(enemy, 'runner', 'west');
// To restore an already dead infected from saved state:
showInfectedCorpse(enemy, 'runner', 'west');
```

Используйте `pixelArt: true` и целое увеличение. 64×64: runner/stalker/clicker; 96×96: bloater/shambler; 128×128: rat-king. Origin `(0.5, 0.875)` совпадает с v3. Смерть и реакции не перемещают объект по карте (`rootMotion: false`). Флаг `infectedDead` защищает пример от повторного запуска; для повторного использования спрайта из пула его нужно очистить и снять обработчик завершения смерти. Состояния живого врага не должны перезаписывать мёртвое состояние.

Полноценная игра, серверное сохранение тел, обыск и обработка коллизий ещё не реализованы. Проверена графика, пример завершения смерти и просмотрщик; запуск в полноценной игровой сцене ещё предстоит.

## Происхождение

Все 1008 прежних PNG из [v3](../infected-animation-pack-v3/README.md), их настройки и прежняя область атласов сохранены без изменений. Новые 144 кадра и 24 тела добавлены из [infected-deaths-v1](../infected-deaths-v1/README.md). Исходники новых поз, референсы и запросы генерации хранятся в этом дополнении. Остальные запросы и история остаются в предыдущих наборах.
