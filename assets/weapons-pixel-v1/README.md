# Оружие — пиксельный концепт

![Все 24 образца](overview.png)

Восемь категорий по три модели: пистолеты, револьверы, двустволки, помповые дробовики, пистолеты-пулемёты, самозарядные карабины, автоматы и винтовки с ручной перезарядкой.

Создано встроенным image_gen. [Запрос генерации](prompt.txt). Это исходный общий визуальный лист. Для всех 24 образцов подготовлены [выстрел и перезарядка](../weapon-animations-v1/README.md): 48 анимаций, 576 прозрачных кадров, один ракурс вправо.
