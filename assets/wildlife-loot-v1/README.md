# Дроп животных — визуалы v1

51 запись ресурсов для всех 20 видов: 31 собственный материал и 20 ссылок на единые порции мяса и рыбы из набора предметов. Общие пищевые ресурсы повторно не экспортируются. [Единый реестр](../../docs/asset-registry.json).

Используются животные выбранного варианта B. Предметы общего типа используют один ID и один визуал у нескольких видов. Графика создана встроенным image_gen; точные запросы — [generation-plan.json](generation-plan.json), исходники — sources, записи происхождения — records.

## Файлы

art/*.png — 256×256; sprites/*.png — 64×64 для инвентаря; ground/*.png — 96×96 для предметов на земле. Собственные материалы: 93 PNG. Пища использует исходные PNG из соседнего item-visuals-v2, без дублирования. Размеры общих изображений — в манифесте. Атласы содержат только 31 собственный материал. Прозрачные атласы и JSON в atlases; для предметов на земле pivot (0.5, 0.8333), для инвентаря (0.5, 0.5). Масштаб изображения задаёт только читаемость и не является физическим размером предмета.

Мясо и материалы изображены отдельными предметами без крови, целых туш и интерфейсных рамок. Шкуры соответствуют окрасу выбранных животных. Перья птиц, рога, клыки и когти имеют собственные визуалы. Кости, сухожилия, жир и некоторые пищевые ресурсы используются несколькими видами.

## Готовность

Это визуальные материалы и таблица соответствия ресурсам. Автоматическое выпадение, разделка, вероятность, количество, рецепты, пищевая ценность и применение ресурсов в игре ещё не реализованы. Таблица не назначает шанс и количество.
