# Заражённые — набор анимаций v1

6 заражённых × 4 анимации × 6 кадров = **24 анимации, 144 отдельных PNG**.

Откройте `preview.html` для просмотра всех движений с регулировкой скорости. В каждой папке `previews` находятся четыре обычных анимированных GIF. PNG и спрайт-листы предназначены для игры, GIF — для просмотра.

## Содержимое

| Папка | Заражённый | Размер игрового кадра |
|---|---|---|
| runner | Бегун | 64 × 64 |
| stalker | Сталкер | 64 × 64 |
| clicker | Щелкун | 64 × 64 |
| bloater | Топляк | 96 × 96 |
| shambler | Шаркун | 96 × 96 |
| rat-king | Крысиный король | 128 × 128 |

В каждой папке:

- `spritesheet.png`: RGBA-лист с 6 столбцами и 4 строками без промежутков.
- `atlas.json`: координаты именованных кадров в формате Phaser JSON Hash.
- `animations.json`: порядок кадров, скорость, зацикливание, точка привязки и визуальная отметка атаки.
- `frames/*.png`: 24 отдельных прозрачных кадра одинакового размера внутри типа.
- `previews/*.gif`: ожидание, ходьба, бег, атака.
- `source-crops.json`: координаты нарезки исходного изображения и контрольные суммы кадров.

Строки листа сверху вниз: `idle`, `walk`, `run`, `attack`. Кадры читаются слева направо, номера `00`–`05`. Направление всех кадров — **south**, вниз к игроку. Другие направления в этот набор не входят.

## Поведение

Ожидание: дыхание и небольшие движения плеч/головы. Ходьба: шаги. Бег: усиленный наклон и движение конечностей. Атака: подготовка, замах, удар и возврат. Тяжёлые виды имеют более медленные настройки кадров. `run` для тяжёлого существа означает тяжёлый рывок.

Ожидание, ходьба и бег зациклены. Атака в JSON проигрывается один раз (`repeat: 0`). GIF и просмотрщик повторяют атаку для демонстрации. Визуальный момент контакта — четвёртый кадр, индекс `3`. У шаркуна это жест выброса спор; отдельное облако частиц не входит в лист.

PNG содержат только внешний вид. Перемещение, коллизии, урон, дистанцию атаки, задержки и сетевую синхронизацию реализует игровой код. Нельзя наносить урон напрямую по событию GIF/анимации без проверки игровой логикой.

## Подключение к Phaser

В `phaser-infected.js` находятся функции загрузки и регистрации анимаций, создания спрайта и короткие примеры. Скопируйте папку набора в каталог статических ресурсов игры. Вызовите `preloadInfected(this)` в `preload`, `createInfectedAnimations(this)` в `create`, затем `addInfectedSprite(this, 'runner', x, y)`. Пример рассчитан на Phaser 3; в полноценном проекте движка он пока не запускался.

Включите `pixelArt: true`; увеличивайте изображения целым множителем. Используйте `origin` из JSON: он соответствует точке на земле под персонажем. Размеры кадров фиксированы, автообрезку отдельных кадров при импорте отключите.

## Статус графики

Это первая итерация для прототипа, созданная на основе выбранного концепта с помощью встроенного image_gen. Позы сгенерированы отдельно по типам, затем нарезаны и упакованы; это не финальная ручная пиксельная анимация. Возможны небольшие изменения деталей между кадрами, особенно у многорукого босса; качество циклов следует оценить в просмотрщике и затем в масштабе игры. Исходники высокого разрешения сохранены в `sources`, полные запросы — в `generation-prompts.json`.

`validation.json` содержит результаты проверки количества кадров и GIF, размеров и границ нарезки. Скрипт сборки проекта: `tools/build-infected-pack.cjs` (Node.js, sharp, jszip). Внешние приложения для просмотра PNG/GIF не нужны.
