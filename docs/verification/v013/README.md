# Проверка 0.13.0

85 тестов прошли; полный вывод — unit-tests.tap. verification.json содержит проверку готового EXE: реальная ходьба героя, инвентарь, подбор и вход/обыск/выход во всех восьми направлениях. Восемь GIF показывают ходьбу и бег всех 18 заражённых по фактическому расстоянию во всех четырёх направлениях — 144 полных комбинации.

Изолированный реальный сейв 0.12 перенесён в новую версию: герой остаётся в повёрнутом доме, нетронутый лут становится случайным, пустой шкаф остаётся пустым, повторная загрузка не меняет припасы. Проверка шести героев в 768 позах подтвердила непрозрачность тела под одеждой, привязки снаряжения и рук для 24 видов оружия.
