# Прототипы базы

Три концепта в стиле раннего арта проекта, с одинаковым наклоном камеры, насыщенной растительностью и плотной детализацией.

- `01-dacha-base.png` — база среди дач: жилой дом, мастерская, теплица, медпункт и общий двор.
- `02-sawmill-base.png` — база на лесопилке: производственный ангар, ремонт техники, склады и жилые домики.
- `03-riverside-base.png` — база у реки: причал, рыбалка, водоснабжение, мастерская и огород.

Назначение: визуальные референсы для выбора планировки. Это не игровые предметы, текстуры или готовая игровая сцена. В каталоги игровых сущностей не включены.

Созданы встроенным image_gen. Полные запросы сохранены в `prompts.json`.
