# Каталог материалов

Все пути ниже относительны корня репозитория. Включены обе итерации заражённых, статичные выжившие, первоначальные концепты, исходники генерации, настройки экспорта, готовые архивы и все скриншоты/контактные листы из папки проекта.

| Путь | Содержимое |
|---|---|
| `assets/concepts/environment-weather-v1.png` | Посёлок, лес, дома, укрепление; солнце, дождь, ночь |
| `assets/concepts/survivors-v1.png` | Первый общий лист стилевых вариантов выживших |
| `assets/concepts/infected-v1.png` | Первый концепт шести заражённых |
| `assets/infected-animation-pack-v1` | 24 анимации, 144 кадра, south; исходники, PNG, GIF, атласы, JSON, просмотрщик |
| `assets/infected-animation-pack-v2` | Актуальные 96 анимаций, 576 кадров, четыре направления; исходники, PNG, GIF, JSON, просмотрщик |
| `assets/infected-animation-pack-v2/comparisons` | 24 сравнительных GIF с четырьмя направлениями рядом |
| `assets/survivor-visuals-v1` | Джоэл, Элли, Томми, Тесс, Билл, Дина: левый бок, правый бок, со спины; общий лист |
| `output/infected-preview-check.png` | Скриншот просмотрщика v1 |
| `output/infected-v2-contact.png` | Контактный лист заражённых в четырёх направлениях |
| `output/qa-v2` | Шесть скриншотов просмотрщика v2, по одному на каждый тип |
| `output/*.zip` | Все три ранее выданных архива: заражённые v1/v2 и статичные выжившие |
| `docs/art-prompts-v1.md` | Первоначальные запросы генерации |
| `assets/**/generation-prompts.json` | Полные запросы для отдельных наборов |
| `assets/**/validation.json`, `verification.json` | Результаты технических проверок экспорта/просмотра |
| `tools` | Нарезка, упаковка, технические проверки и публикация |

Предыдущие версии сохранены намеренно. Анимации v1 и v2 содержат те же шесть типов: их нельзя суммировать как 12 уникальных заражённых.

## Открытие

PNG/GIF можно просматривать прямо на GitHub. Для интерактивного просмотра клонируйте/скачайте репозиторий целиком и откройте `assets/infected-animation-pack-v2/preview.html` локально. Никакой игровой сервер для этого не нужен.

Для персонажей откройте `assets/survivor-visuals-v1/overview.png`; отдельные листы находятся рядом. Это статичные концепты, а не игровые анимации.

## Полный перечень

`asset-inventory.json` содержит точный путь, размер и SHA-256 каждого проектного файла на момент первоначальной подготовки. Сам файл перечня исключён из собственного списка, чтобы избежать циклической контрольной суммы. Служебный каталог `.git` и установленные зависимости не входят в перечень.
