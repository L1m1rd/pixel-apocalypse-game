PNG/GIF доступны на GitHub. HTML-просмотрщики открываются локально после скачивания проекта.

[Архивы выживших](../assets/survivor-friends-animations-v1/downloads): весь набор анимаций, отдельные наборы шести героев, реалистичные арты и статичные пиксельные модели.

Старые наборы и дублирующие ZIP/скриншоты исключены из текущего дерева публикации. [Конфигурация публикации](../publication-config.json) задаёт актуальные папки и локальные исключения. Старые материалы доступны через историю Git.

[Перечень файлов](asset-inventory.json) содержит пути, размеры и SHA-256; пересоздаётся командой `npm run inventory`. Зависимости, Git, временные и исключённые файлы в него не входят.
