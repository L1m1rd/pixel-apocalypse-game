# Северные дачи — отдельная ветка

Рабочая ветка этого чата: `codex/northern-dachas` в `L1m1rd/pixel-apocalypse-game`.

По запросу пользователя от 19 октября 2026 года после каждого завершённого запроса проверяем и коммитим готовые изменения этого чата, затем отправляем их в эту ветку GitHub. Не включаем незавершённые изменения других чатов, не коммитим `.env`, зависимости, пользовательские сохранения и локальные сборки. Основная ветка `master` остаётся отдельно.

Карта: 80 участков, 60 дач, восемь секторов, проезды, река, мост, лесополоса, кольцевая дорога. Графика — канонический набор `assets/northern-dachas-v1`. Дома пока непроходимые статические постройки; подготовка интерьеров — отдельный этап. Заражённые и бой пока не подключены.

Запуск: установить зависимости корня и `desktop`, выполнить `npm run prepare:desktop`, затем `npm start`. Сборка: `npm run build:desktop`. Локальная готовая сборка содержит все ресурсы и не требует Node.js.

Управление: WASD / стрелки — движение в направлениях экрана, Shift — бег, C / Ctrl — присесть, E — открыть/закрыть ближайшие ворота, M — обзорная карта, колесо — масштаб, H — скрыть интерфейс, Esc — закрыть карту / пауза, F11 — полный экран.

Эта ветка использует отдельную папку сохранений `PixelApocalypse-NorthernDachas`, чтобы не затронуть мир другой сборки. Сохраняются герой, позиция и открытые ворота.

Проверки: `node --test desktop/core.test.mjs desktop/northern-dachas-map.test.mjs`, `node tools/check-asset-consistency.cjs`, `node tools/check-northern-dachas.cjs`, `node tools/check-northern-dachas-runtime.cjs`.
