# Проверенные ошибки 0.11

В ходе разработки устранены: скрытое тестовое окно не получало кадры достаточно часто; мини-карта показывала сетку пустого полигона; большие деревья заслоняли мебель при входе в дом; доступ к открытому ранее контейнеру не перепроверял нахождение внутри; закрытые двери не прерывали линию стрельбы. Для прохода, сохранения, коллизий и доступа к луту добавлены проверки.

Открытых воспроизведённых ошибок, блокирующих основной цикл, по завершённым проверкам нет. Это не подтверждает отсутствие любых ошибок. Визуальное соответствие референсу частичное: реализация не повторяет каждый пиксель статичного арта.
