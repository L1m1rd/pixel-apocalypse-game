# Архитектура 0.11

Electron + Canvas + ES modules. renderer запускает непрерывное выживание непосредственно в изометрической карте. campaign UI не создаётся. village-world хранит детерминированную сцену, участки, дороги и столкновения; village-renderer — землю, глубину, статическое солнце, тени и разрез домов. survival-engine управляет жизнью, предметами и противниками; inventory сохраняет карманы, экипировку и содержимое каждого рюкзака.

Декоративная сцена восстанавливается детерминированно; интерактивные объекты и их состояние сохраняются. JSON проверяется в survival-save и save, запись атомарная. Новый отдельный профиль — PixelApocalypse-ContinuousSurvival. Состояние смерти остаётся в сохранении, новая попытка очищает инвентарь и добычу.

Мебель разрешается из canonical owner в docs/asset-registry.json. prepare-village-assets экспортирует только runtime копии в игнорируемый desktop/media и сохраняет исходные ID и варианты. Новых предметов и PNG-копий в каталогах исходных материалов нет.

Проверки охватывают достижимость всех 80 входов, коллизии, непрозрачность стен для стрельбы, сохранение внутри дома, настоящий проход клавишами, обыск, выход и частоту кадров.
