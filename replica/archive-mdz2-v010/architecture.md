# Архитектура

Сохранён существующий стек Electron + ES modules + Canvas: он уже поддерживает локальные сохранения и собственные канонические материалы. Новые функции не требуют аккаунтов, оплаты или сервера; фиктивная авторизация и фиктивные сетевые вызовы не добавляются.

campaign-rules — постройки, районы, рецепты и баланс. campaign-engine — операции со складом, ресурсами, отрядом, очередями, вылазками и эвакуацией. campaign-world — генерация районов и восприятие противников. campaign-ui — S02/S03/S05/S07/S08/S09. inventory и survival-engine — S04/S06. campaign-save — ограниченная проверка входных данных. renderer связывает экраны с игровым циклом.

Хранение — атомарный JSON через основной процесс Electron. Новый профиль PixelApocalypse-CampRaids сохраняет старые выпуски отдельно. Схема хранится в коде sanitizeCampaign; SQL не нужен локальной однопользовательской игре. Абсолютные сроки считаются по UTC epoch; восстановление после закрытия ограничивает начисление производства одним днём. Смена часов назад не создаёт ресурсы.

Команды: selectSurvivor; store/take/convert; upgrade; recover; craft/repair/modification; launchManual/launchAuto; beginExtraction; finishRaid. Каждая проверяет режим, статус, наличие предмета, вместимость и цену до изменения состояния. Повторная доставка задачи исключена удалением из очереди до выдачи результата.

Порядок реализации: F01 полностью → склад и отряд → база и очереди → скрытность/бой/видимость → автоматические задания и сохранение → F06/F07 → регрессия прежних систем. Основные риски: потеря или дублирование предметов, повторная выдача фоновых результатов, сброс активного рейда при загрузке. Они проверяются отдельными тестами.
